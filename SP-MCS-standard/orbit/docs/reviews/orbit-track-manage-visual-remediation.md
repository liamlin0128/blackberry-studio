# 轨道管理视觉评审处理记录

本记录对应《轨道管理视觉评审意见单（专家 A）》。用户已裁决：轨道计算系统与任务规划系统共享同一套应用壳层；因此，涉及两套系统壳层差异时，以任务规划系统的现行规范为准。

| 编号 | 处理结论 | 实施内容 |
| --- | --- | --- |
| V-01 | 已采纳，并按用户裁决调整 | 左侧导航统一为 250px，系统标题 58px，菜单分组与叶子项均为 48px；激活态、背景和缩进复用任务规划系统。 |
| V-02 | 已采纳，并按用户裁决调整 | 移除轨道计算系统独立的真实系统品牌表现，统一为 SP 圆形标识、`星枢任务控制系统` 与 `SP-MCS` 副标题，以及同款用户区域。 |
| V-03 | 已采纳 | 顶栏、主色、表面色、边框、圆角继续引用 `docs/ui-spec.md` 的 SP-MCS 语义令牌；不将原系统的深灰菜单主题带入共享壳层。 |
| V-04 | 已采纳 | 头部通知、用户、信息与下拉入口改用项目 SVG 图标；页面标签、设置和可见弹层关闭入口统一使用同一 SVG 图标组件。 |
| V-05 | 部分采纳 | 固化弹层头部、正文、底部、表单行和结果块的公共规则；不把“定轨结果”的专业结果块强制套用到历史记录与配置弹层，避免改变业务层级。 |
| V-06 | 已验证 | 对 1440px、1280px、1024px 进行桌面宽度走查。1024px 保持固定壳层；宽表仅在表格容器内横向滚动。 |

## 验收边界

- 本次只统一视觉壳层、图标和组件语法，不改变轨道管理的字段、导航、入口或业务结果。
- 任务规划系统是共享头部与左侧导航的唯一视觉源；后续新增轨道计算页面必须复用同一套令牌和壳层尺寸。
