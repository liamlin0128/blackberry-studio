# 用户流程

## 核心路径

1. 操作人员在任务规划系统顶栏点击“轨道计算系统”。
2. 浏览器打开轨道计算系统工作台（`127.0.0.1:5174`）。
3. 操作人员通过顶栏“任务规划系统”或工作区“进入任务规划系统”返回任务规划原型。

## 分支与异常

- 点击系统说明图标时，显示或收起简短的 SP-MCS 系统说明。
- 未建设的其他系统模块不提供跳转，避免产生无目标的交互。
- 若另一个原型未运行，浏览器会显示本地连接失败；预览服务由各原型的启动脚本分别管理。

## 轨道管理试点流程

1. 打开独立运行的轨道计算系统，默认进入“轨道管理”。
2. 在“卫星”筛选中选择全部、MD1A 或 MD1B；点击重置返回全部。
3. 点击“定轨计算配置”，查看自动定轨开关和每日计算时刻（19点），可保存或取消。
4. 点击“历史轨道”，在历史表中点击“查看”，进入“定轨结果”。
5. 点击“开始计算”时先确认；确认后的服务提交和状态反馈待真实流程证据确认。

6. 历史轨道当前仅允许查看已捕获的第 1 页；后续页码与跳转在获得数据前保持禁用。

7. 在历史轨道中点击“手动输入”，可选择 TLE 或瞬根并填写对应字段；保存后直接在当前卫星的历史轨道首行新增记录并更新总数。真实服务端落库与编号规则待接口证据确认。
8. 定轨配置保存后，关闭并重新打开配置弹层可回显本次在原型内的选择。
9. 在历史轨道中选择“数据更新时间”的起止范围并点击“检索”，表格仅显示当前卫星中处于该范围内的已加载记录；无匹配记录时显示空态。

## 2026-11-02 版本切换

用户在当前系统顶栏查看版本标识，点击切换入口后进入同一系统的另一版本独立预览地址；侧栏菜单起始位置不受版本入口占用。

## 辅助计算

1. 在坐标转换页选择源系统、填写六个数值与北京时间历元、选择目标系统，点击“转换”查看结果；支持 JSON 导入和复制。
2. 在时间转换页选择 BJT 或 UTC、填写时间点，点击“转换”查看十项时间表示；超过闰秒有效期时显示错误而不输出结果。

## 2026-11-12 事后精密定轨（标准版）

1. 在“事后精密定轨”选卫星和不超过 48 小时的北京时间数据区间，查询并多选同一卫星的一条或多条原始观测量记录。点击下一步时校验每条记录时间有效，且排序后的区间无断档；不连续则留在第一步并提示重选。
2. 系统依据已选记录的最早开始和最晚结束时间查询历史遥测定位数据。查询中显示加载动画；找到时展示覆盖时间和数据条数后允许进入下一步；未找到时提示无法定轨，用户人工确认或返回第一步重新选择。
3. 核对六类辅助文件，可选择本地文件替换显示的文件名；返回上一步时保留选择。
4. 再次校验记录连续性后确认发起原型模拟计算，查看实际所选记录条数、0% 进度与结果空态；摘要不展示定轨数据与辅助文件统计。终止需确认，退出返回第一步。

## 2026-11-13 轨控策略计算（标准版）

1. 页面发起方式固定为“直接使用当前轨道”；从下拉框单选一颗卫星，系统展示只读的当前轨道、轨道历元、高度、双星距离和数据源。
2. 选定卫星后，页面从标定数据中只读展示该星的电推进器参数。无标定数据时提示人工确认并阻止发起计算。
3. 目标轨道选择“标称轨道高度”或“自定义”；两种选择下均填写可正可负的修正高度（米），按需填写非负的高度残差（米），确认后发起计算；缺少卫星或数值无效时阻止提交。轨道保持监测页不提供将结果带入策略计算的入口。
