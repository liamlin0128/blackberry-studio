# 阶段 1 覆盖清单与差异说明

| 真实页面证据 | 原型组件/交互 | 覆盖情况 |
| --- | --- | --- |
| 轨道管理标题、卫星筛选、定轨计算配置入口 | `OrbitTrackManagePage.tsx` | 已覆盖 |

## 差异与原因

| 项目 | 当前处理 | 原因 |
| --- | --- | --- |
| 技术栈 | 保持已有 React/Vite/Tailwind 项目，不迁入 Vue/Element Plus | `prototype.config.json` 与项目规则指定既有 React 栈；两个系统保持独立仓库 |
| 非试点菜单页面 | 只展示名称，不提供伪造跳转 | 尚未完成字段、布局和流程证据盘点 |
| 开始计算后反馈 | 仅执行前确认 | 提交结果和状态变化未被证据确认 |
| 历史轨道具体数据 | 仅放入与已见模式一致的最小记录集合 | 原快照有大量记录，阶段 1 不扩充未逐项验证的数据 |
| 检索 | 保留入口外观，业务结果待确认 | 未捕获后续页面或提示状态 |
| 手动输入、复制 | 已按截图与产品裁决实现本地交互 | 服务端落库、检索与失败状态尚无证据 |
