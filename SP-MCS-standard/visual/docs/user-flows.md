# 用户流程

## 实例记录与日志

1. 在实例列表通过类型、状态和时间范围组合检索。
2. N 开头的编号代表在线实例，S 开头的编号代表模拟实例；各自从 1 递增。
3. 点击“日志”打开当前实例的操作日志；列表与卡片均不提供“详情”入口。
4. 在日志弹层按“类型”或“操作类型”筛选，必要时定位到顶部或底部；“导出日志”下载当前筛选结果。
5. 在实例列表选择类型、一个或多个状态和时间范围后点击“查询”；点击“重置”恢复全量记录。
6. 点击“创建实例”，填写实例名称与备注说明；下一步选择场景和一个或多个实体模型；确认内容后保存，新记录同时出现在列表和卡片视图。

## 核心路径

1. 从统一头部的“可视化仿真系统”进入系统。
2. 在左侧“模型管理”打开“模型列表”。
3. 输入“搜索模型”按模型名称筛选表格；清空输入后恢复全部记录。
4. 点击编辑、版本管理或添加模型，保留原始入口反馈；详细目标待确认。
5. 点击删除，确认后从原型内列表移除该行并提示“已删除”。

## 仿真管理扩展路径

1. 在左侧“实例管理”打开实例页面，默认展示列表视图；通过页面内“列表视图 / 卡片视图”切换展示方式。
2. 在实例列表中搜索实例；启动、暂停或关闭后切换到同页卡片视图可见一致状态。关闭前必须确认。
3. 在左侧“场景管理”打开场景列表，按场景名称检索；删除前必须确认。
4. 任一页面可追加 `?state=loading`、`?state=empty`、`?state=error` 或 `?state=forbidden` 检查非正常状态。

## 模型与场景管理补全路径

1. 在模型管理中按分类、仿真版本、名称和是否启用筛选关联模型；“卫星模型”下可选择二级的相机模型和固存模型；可直接切换模型启用状态。
2. 点击“仿真版本管理”查看版本内按模型分类汇总的关联模型；点击“添加版本”填写版本号、使用引擎、使用模型和压缩包入口，保存后回显为当前版本。
3. 点击“添加模型实体”或模型卡编辑按钮，填写模型文件、名称、简称、版本、类型、组合及说明，保存后更新关联模型卡。
4. 在场景管理中按场景名和场景类型检索；点击查看打开只读详情，点击编辑打开基本信息、模型集、XML 文件三个页签。
5. 编辑模型集时，通过卡片式多选弹层按类型选择场景模型；模型集以一行一个模型展示，每个模型可重复添加多个实体；XML 文件由当前模型/实体配置构建，可导出为 XML 文件。

## 风险操作

删除前必须确认；取消不改变列表。真实服务端的执行中、成功和失败反馈待确认。
