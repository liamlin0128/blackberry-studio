头部原“资源管理”位置显示不可点击的“接入与权限系统”占位；资源管理入口移至任务规划系统侧栏，可视化仿真菜单不变。

## 2026-10-13：实例记录与日志

- 实例列表展示编号、实例类型、仿真类型、场景、状态和运行时长。
- 在线实例以 `N` 递增编号（N1 为首条），模拟实例以 `S` 递增编号（S1 为首条）。
- 实例操作不提供“详情”，改为“日志”；日志仅展示当前实例的操作记录。
- 日志弹层展示实例编号与运行状态，提供类型、操作类型筛选；日志表字段为序号、时间、类型、操作类型、描述、来源、操作者，并提供顶部/底部定位和本地导出入口。
- 实例列表增加检索条件：类型（在线仿真、模拟仿真、推演仿真）、可多选状态（离线、初始、运行、暂停、停止、关闭、失败）和开始/结束时间；条件经“查询”生效，“重置”清空全部条件。

## 已完成范围

- 建立独立的 Vue 3 + Element Plus 原型仓库，并通过统一头部与任务规划系统、轨道计算系统互相导航。
- 实现“模型管理 / 模型列表”试点页；路由为 `/app/mccs/visualsys/model/list`。
- 保留已取证的页面标题、说明、添加模型入口、搜索入口、表格字段与顺序、状态和行操作。
- 实现“实例管理”与“场景管理 / 场景列表”；路由分别为 `/app/mccs/visualsys/instance/list`、`/app/mccs/visualsys/scene/list`。
- 实例管理默认展示列表视图，并在同一页面切换卡片视图；启动、暂停、关闭后可即时回显。关闭实例、删除场景和删除模型必须先确认。
- 三个业务页面均覆盖正常、加载、空、错误和无权限状态；实例卡片是实例管理的同页视图，不单列路由页面。

## 2026-10-21：创建实例与关键确认

- 创建实例按实际页面证据使用三步流程：基本信息（实例名称、备注说明）→ 模型、场景设置（场景选择、实体模型）→ 确认保存。
- 创建后在实例列表和卡片视图中即时回显；在线、模拟、推演实例的编号分别按 `N`、`S`、`T` 前缀递增。
- 模型启用/停用必须先确认，取消不修改当前状态；确认文案需要明确说明启用或停用对当前仿真版本可用性的影响。
- 场景和模型的时间字段显示北京时间（UTC+8）。

## 2026-10-13：模型与场景实际系统补全

- 模型管理改为“模型分类 + 仿真版本条件 + 关联模型卡片”的工作区；完成仿真版本管理、添加版本、添加模型实体、编辑模型实体和启停开关。
- 场景管理按实际系统还原场景名/场景类型检索、字段完整的列表、查看与编辑弹窗；编辑弹窗覆盖基本信息、模型集、实体表及 XML 文件。基本信息不展示仿真时间精度。

## 2026-10-14：场景模型集结构

- 模型集以单列模型行展示；每行对应一个场景模型，并在该行下维护该模型的多个实体。
- “添加场景模型”使用带模型分类筛选的卡片式多选弹层，确认后将所选模型纳入模型集。
- 模型、版本和场景编辑在原型内保存后即时回显；不呈现未经证据确认的服务端保存成功、解析成功或运行成功提示。

## 2026-10-13：用户确认模型分类调整

- 移除“激光通信模型”和“北斗终端模型”，不再出现在分类导航、模型实体、版本关联或模型类型选项中。
- “卫星模型”为一级分类；“相机模型”和“固存模型”为其下的二级模型。“卫星模型”筛选包含卫星、相机和固存三类实体。
