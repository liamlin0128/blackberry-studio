# 可视化仿真系统 UI 标准

本产品复用 SP-MCS 任务规划系统、轨道计算系统的壳层和桌面端数据密度规范；业务字段与流程以可视化仿真系统的实际页面证据为准。

## 壳层与布局

- 固定深色全局头部高度 64px；品牌区、系统名称、一级系统切换和用户区与另外两个系统保持一致。
- 左侧导航宽度为 250px，在 1100px 以下收至 230px；一级菜单使用领域图标，当前二级菜单使用浅蓝选中态。
- 内容区包含 40px 页面标签、页面标题及说明、查询区和业务内容区。页面在 1440px、1280px、1024px 宽度下可读；窄宽度时表格仅在内容区内横向滚动。
- 表格表头与行高均为 42px，表头底色为 `#f2f5f9`；常规操作使用蓝色链接，关闭、删除等危险操作使用红色并要求确认。

## 颜色与状态

- 主色 `#165dff`；画布 `#f6f8fb`；卡片 `#ffffff`；边框 `#e3eaf3`。
- 运行中/启用使用绿色状态标签；已暂停使用琥珀色；初始、已停止、归档使用灰色。
- 状态色仅用于状态，不替代同层级的操作语义。

## 交互与反馈

- 查询条件点击“查询”后生效；“重置”恢复初始条件。
- 创建、编辑、上传选择等交互在本原型内即时回显，不宣称服务端执行结果。
- 关闭实例、删除记录、启用或停用模型等会改变可用性或运行状态的操作，先展示明确的二次确认；取消不改变现有数据。
- 所有日期时间字段标注时区；本系统展示时间统一使用北京时间（UTC+8）。
- 正常、加载、空、错误、无权限状态通过路由 `state` 参数可分别验收；无权限状态仅用于界面状态展示，不实现权限策略。

## 组件与技术边界

- 仅使用 Vue 3、TypeScript、Vite、Element Plus、Vue Router 与 Pinia。
- 领域数据位于 `src/mocks/`，类型位于 `src/types/`，页面只组合领域组件与状态；不得将同类业务数据散落到根组件。
- 不在用户界面中出现“原型”“模拟数据”等会被误认为业务要求的提示语。
