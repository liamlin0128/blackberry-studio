## 模型管理

| 区域 | 已确认内容 | 原型对应 |
| --- | --- | --- |
| 分类 | 源页面实体模型下含卫星、相机、固存、激光通信、地面站、北斗终端等分类 | 左侧分类筛选 |
| 条件 | 仿真版本、名称、是否启用；入口为“仿真版本管理” | 顶部筛选区 |
| 关联模型 | 添加模型实体；模型卡展示名称、启用开关、类型、模型 ID、创建时间、模型版本；可编辑 | 关联模型卡片及编辑弹窗 |
| 版本管理 | 展示 V1.0 与按类别分组的模型；可添加版本 | 版本管理弹窗 |
| 添加版本 | 版本号、使用引擎、使用模型、上传；仅 zip 且不超过 50 MB | 添加版本弹窗 |
| 编辑模型 | 模型文件、模型名称、模型简称、模型版本、类型、模型组合、模型说明 | 模型实体编辑弹窗 |

### 用户确认的分类调整

- 激光通信模型和北斗终端模型不纳入当前原型。
- 相机模型、固存模型作为卫星模型下的二级模型；卫星模型筛选包含卫星本体及两个二级模型。
