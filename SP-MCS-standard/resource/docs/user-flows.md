# 资源管理原型用户流程

## 2026-10-29 入口变更

从任务规划系统侧栏展开“资源管理”，选择卫星管理、光学载荷管理或天线管理；内容在任务规划系统框架内切换，任务规划头部和侧栏保持可见。

1. 在任务规划系统侧栏展开“资源管理”并点击子菜单，内容区展示独立仓库维护的对应页面。
2. 输入卫星ID、中文名或更新时间范围，点击“查询”；“重置”清空条件并恢复两条证据记录。
3. 点击行内“编辑”或“查看”，在五个页签浏览卫星关联内容；编辑保存仅更新当前原型会话状态。
4. 点击“工作时段”查看当前卫星记录，可打开“新增时段”并填写状态、起止时间和备注。
5. 点击“星上站点管理”查看当前卫星站点，可添加、行编辑和删除，最后保存全部。
6. 勾选卫星点击“删除”，在确认弹窗后移除当前原型会话中的记录。

真实服务端的持久化、导出文件格式、权限和错误反馈流程待确认。

## 阶段 2 修订流程（2026-10-28）

1. 在筛选区填写卫星 ID、中文名和“更新时间”起止日期时间，点击“查询”；页面统一标明时间为北京时间，边界含所选秒。点击同一区域的“导出”，下载当前查询结果；“重置”恢复全部记录。
2. 新增或编辑卫星时，基本信息的已证实必填项为空则停留在“基本信息”页签并提示字段；光学载荷新增行填写名称与不超过 16 字符的编号后才能保存。未填写的空载荷行不会计入载荷数。
3. 在星上站点弹层，添加或编辑一行后填写存储号码、地面站设备 ID 和名称，再点击该行“确定”。正在编辑或未确认的行阻止“保存全部”；取消弹层则丢弃本次草稿。
4. 工作时段输入按北京时间填写，开始时间早于结束时间后方可确定。列表、编辑页签和弹层各自只标注一次时间基准。
5. 加载、空、错误、无权限状态沿用统一状态面板，可由评审用 `?state=loading|empty|error|forbidden` 检查；默认进入正常列表。真实接口如何触发这些状态待核。

## 2026-10-30 切换版本
用户在侧栏顶部查看当前版本，点击切换入口后跳转到另一版本固定地址。


## 2026-11-02 版本切换

用户在当前系统顶栏查看版本标识，点击切换入口后进入同一系统的另一版本独立预览地址；侧栏菜单起始位置不受版本入口占用。
