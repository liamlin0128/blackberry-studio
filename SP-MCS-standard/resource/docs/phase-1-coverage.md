# 阶段 1 覆盖清单与差异

| 页面/区域 | 已实现 | 证据差异与后续 |
| --- | --- | --- |
| SP-MCS 头部和侧栏 | 统一品牌、顶部切换、资源菜单 | 资源管理为独立产品；沿用既有样式 |
| 卫星管理列表 | 查询、重置、导出、新增、删除、列表列、分页、行操作 | 列表数据仅有 HTML 中两条记录；其它分页无数据证据 |
| 卫星编辑/查看 | 五个页签和已确认字段 | 下拉全集、批次拆分、真实服务端校验待确认 |
| 工作时段 | 空表、新增时段弹层、当前会话更新 | 服务端结果待确认 |
| 星上站点管理 | 表格、行编辑/删除、添加、保存全部 | 仅选取证据中前 3 条站点作试点；其余站点尚未录入 |
| 光学载荷管理、天线管理 | 导航和路由 | 本阶段尚未还原业务页面；素材已盘点 |

当前原型中的新增、编辑和删除仅维护浏览器内存。界面不展示“模拟数据”“原型模拟”等可能被误认为业务需求的提示。加载、接口错误、无权限状态因缺少页面证据暂未还原。
