# 测试与评审场景

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 创建实例 | 点击“创建实例”，完成名称、备注、场景和实体模型选择后保存 | 三步向导按顺序展示；缺失必填项不可进入下一步；保存后新记录在列表与卡片视图可见 |
| 模型启停确认 | 切换模型启用开关并分别取消、确认 | 取消后开关保持原状态；确认后状态标签/筛选结果同步更新，且确认文案明确操作影响 |

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 实例卡片操作 | 切换到卡片视图并悬停每个操作图标 | 图标分别提示启动/暂停、关闭、重启、日志；关闭仍弹出确认框；操作结果与列表视图一致 |

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 实例记录与日志 | 查看列表中 N1、S1 记录并点击操作区末位的“日志” | N1 标识第一个在线实例、S1 标识第一个模拟实例；日志弹层仅展示被选中实例的操作记录，列表不再出现“详情” |
| 日志弹层筛选与导出 | 打开 N1 日志，按类型或操作类型筛选，再点击顶部、底部和导出 | 标题显示编号和状态；表格显示七个证据字段；定位只滚动日志表，导出当前筛选结果为本地 CSV |
| 实例组合检索 | 选择“在线仿真”、状态“运行”与包含 N1 记录时间的范围后查询，再点击重置 | 仅显示同时满足条件的记录；状态可多选；重置后显示全部实例 |

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 模型分类筛选 | 选择卫星模型、其下的相机模型或固存模型、地面站模型 | 卫星模型显示卫星及两个二级模型；二级筛选只显示对应模型卡片 |
| 实例视图切换 | 进入实例管理，点击“卡片视图”后再点击“列表视图” | 默认显示列表；两种视图在同一路由切换，实例状态和检索结果保持一致 |
| 模型条件筛选 | 输入名称或切换是否启用 | 模型卡即时过滤；重置恢复全部关联模型 |
| 仿真版本管理 | 打开版本管理、查看 V1.0 分类模型 | 展示卫星模型及其二级相机/固存模型、地面站模型的关联模型 |
| 添加版本 | 填写版本号、使用引擎，勾选模型后保存 | 新版本成为当前版本并在模型区回显 |
| 添加/编辑模型实体 | 填写必填的模型名称、模型简称后保存 | 新模型插入当前版本；编辑模型实时更新卡片字段 |
| 场景检索 | 输入场景名或选择场景类型 | 表格仅展示符合条件的记录；重置恢复结果 |
| 场景详情 | 点击查看 | 展示基本信息、模型集实体表和 XML 文件内容 |
| 场景编辑 | 在基本信息、模型集、XML 文件中调整内容后保存 | 列表回显场景名称、简称、编辑人与编辑时间的变更 |
| 场景模型与实体 | 打开添加场景模型，按类型筛选并选择模型后确认；在任一模型行多次点击添加实体并填写 Name | 所选模型新增为独立模型行；每个模型行下的 type、Name、parameter、tle 表可累积新增多个实体 |
| XML 文件 | 在 XML 页签点击导出 XML | 下载由当前模型与实体配置构建的 XML 文件 |
| 非正常状态 | 在模型或场景路由追加 `state=loading|empty|error|forbidden` | 分别显示加载、空、错误、无权限状态，正常业务区不展示 |
| 桌面适配 | 检查 1440px、1280px、1024px | 头部、侧栏与工作区可读；窄宽度下表格在内容区横向滚动 |

## 顶栏版本切换

标准版与 0701 版分别检查：顶栏入口可见且不遮挡系统导航；侧栏不出现版本卡片；点击后进入同一系统的另一版本地址。资源嵌入模式不显示第二套头部。
