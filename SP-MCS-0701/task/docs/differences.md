# 阶段 1 差异说明

本文件记录 2026-09-10 的阶段 1 调整。资源管理“提升为顶部入口”的当时方案已被 2026-10-29 决策取代；现行菜单和仓库边界以 `docs/requirements.md`、`docs/decisions.md` 和 `AGENTS.md` 为准。

## 本轮（2026-09-10）基于 HTML 证据的调整

| 证据或反馈 | 原型调整 | 性质 |
| --- | --- | --- |
| 原系统列表无表格竖线 | 移除列表及详情子表的 `border` 模式，仅保留浅色横向分隔与悬停反馈 | 保真并规范化 |
| 表格应随页面变化 | 页面改为纵向弹性布局，表格区域自动占据剩余高度；列使用最小宽度和自动表格布局，窄屏保留横向滚动以避免丢字段 | 体验提升 |
| 原系统日志为详情右侧可开合轨迹 | 详情头部增加“日志”开关，右侧独立状态轨迹面板，主内容与日志分别滚动 | 结构保真、视觉提升 |
| 原系统日志层级弱 | 每条日志使用状态、事件、时间三级层次与状态色节点；明确 UTC+8 | 规范化 |
| HTML 保存文件包含大量打包脚本、内联样式和 SVG | 未复制 HTML、脚本或资源；只将已确认结构重新实现为 Vue 组件 | 代码治理 |
| 模板整库注册 Element Plus | 改为页面局部引用实际组件、路由懒加载并删除未引用模板图标；原约 1027 kB 单包拆为约 243 kB 主包和 350 kB 页面包，消除大于 500 kB 的构建警告 | 代码治理 |
| 原系统头部包含特定项目品牌及三个系统名称 | 替换为通用产品品牌 SP-MCS 与“星枢任务控制系统”；完整名称、简介和命名释义通过低干扰说明入口呈现 | 产品化调整 |
| 原系统顶层导航属于更大的地面系统 | 重构为独立产品的五系统导航，阶段 1 仅开放任务规划系统；左侧删除其他系统入口 | 信息架构调整 |
| 原系统点击用户名称显示账户卡片 | 新增通用演示用户账户卡片，保留账号管理与退出登录入口；未确认的跳转和真实鉴权行为不臆造 | 结构保真、交互规范化 |
| 资源管理原位于任务规划系统左侧菜单 | 提升为顶部第六个一级入口，并以轻微分隔标识跨系统公共能力；页面目标待建设 | 产品信息架构调整 |
| 筹划计算顶部原为三个独立色块 | 保留进度、下次时间、开始/设置入口的左右结构，统一为低饱和卡片和清晰信息层级 | 视觉规范化 |
| 原日志详情为逐行长文本 | 保留序号、时间、阶段、正文与详情，改为可扫描的结构化日志列表 | 可读性提升 |
| 大区域筹划原地图区域依赖线上地图 | 保留地图骨架、比例尺、坐标和控件，使用脱机示意并标注“范围形状待确认” | 证据边界控制 |
| 原页面信息卡片层级较弱 | 任务信息与业务内容拆为一致卡片，字段名称和值形成稳定双列网格 | 视觉规范化 |
| 筹划记录时间范围输入占比过大 | 改为 340px 固定比例，1024px 下收敛到 310px，操作按钮保持右对齐 | 响应式优化 |
| 表格进度数字会被右侧固定列遮挡 | 百分比改为前置固定宽度，进度条保留在后方，窄化时优先保证数值可见 | 信息可读性修正 |
| 下次筹划时间卡层级单一 | 改为计划标签、日期、分段时分秒和独立 UTC+8 标识 | 视觉精细化 |
| 大区域页右上角重复路径提示 | 删除“任务规划 / 需求管理”，保留页签和左侧导航表达位置 | 信息降噪 |
| 补充设计给出计算完成后的完整页面 | 在现有规划计算区下方增加结果可视化、统计、执行窗口和条带分析；按评审意见移除计算日志 | 流程补全并精简操作 |
| 补充 HTML 内置大型地图 SVG 与原生交互脚本 | 未复制地图资源和脚本；以 Vue 状态、Element Plus 控件及轻量 CSS 示意实现同等信息结构 | 代码治理 |
| 结果数据只属于 RW202608260121005 | 仅该证据任务可产生对应模拟结果；保留旧任务证据但不混用计算结果 | 数据边界控制 |

## 保留的刻意差异

- 原系统完整表格宽度超过窄屏可视区；原型不隐藏已知字段，在 1280px/1024px 下允许横向滚动。
- 地图仍是证据示意而非真实地图服务；范围形状、图层、交互和数据精度待确认。
- 真实高风险动作、导出、关联计划跳转仍不连接后端。
