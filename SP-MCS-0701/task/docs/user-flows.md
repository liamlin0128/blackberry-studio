# 用户流程

## 2026-10-29 资源管理入口

在任务规划系统侧栏展开“资源管理”，点击“卫星管理”“光学载荷管理”或“天线管理”，页面在同一任务规划系统框架内显示。资源管理页面由独立仓库维护。

## 2026-09-16 跨入口联动

1. 在任务需求列表勾选一条或多条记录，点击“规划计算”，确认影响范围后进入正式规划计算页面。
2. 在任务需求列表仅勾选一条记录，点击“区域筹划”，系统携带该任务内容进入区域筹划页面；多选时提示重新选择。
3. 在上注文件登记列表点击“创建计划”，打开共用的手动创建计划弹窗，计划类型显示并锁定为“上注”。
4. 点击甘特图计划条或计划号，打开与任务计划列表相同的计划详情弹窗。
5. 在手动测控时段列表点击编辑，使用与创建相同的字段回填记录；完成冲突检测后保存更新。
6. 在账户菜单点击账号管理，填写当前密码、新密码和确认新密码后完成修改。

## 2026-09-16 规划计算管理补齐流程

1. 在算法管理点击编辑图标，修改回填的已知字段并保存，列表同步更新。
2. 在状态列点击启用或停用，取消确认时记录不变，确认后仅改变本地状态并反馈。
3. 在应急任务需求处理组合筛选条件后查询；可打开应急计划处理配置，调整上注时间参数并提交本地模拟保存。
4. 在参数管理切换配置分类和版本集合，编辑单项参数值或保存配置，均仅产生本地模拟反馈。

## 核心路径

1. 操作员通过顶部产品系统导航进入任务规划系统；阶段 1 的其他系统入口不可用。
2. 左侧只呈现任务规划系统菜单，操作员进入需求管理 > 任务需求列表。
3. 输入筛选条件，必要时展开创建时间、优先级、执行卫星；点击查询后提交本地筛选，点击重置同时清空编辑中和已提交条件。
4. 浏览任务状态、时间窗、关联计划及统筹结果；点击关联计划编号时复用任务计划详情弹层。
5. 点击“查看”打开同页详情弹层；关闭后返回原列表位置。
6. 点击“编辑”打开同页编辑弹层，调整优先级，经确认后保存并获得结果反馈。

## 分支与异常

- 未选择记录触发批量入口：提示先选择记录。
- 删除、取消、完成：确认后才执行本地模拟；真实影响范围和失败规则待确认。
- 关联计划：完整计划记录打开既有计划详情；只有关联编号证据的计划仍复用同一弹层，未知详情字段标记「待确认」。
- 加载、空、错误、无权限使用查询参数模拟，不连接真实服务。

## 筹划计算

1. 从需求管理进入“筹划计算”，查看当前进度与下次筹划时间。
2. 设置开始时间范围并点击查询，查看范围内的完成/超时记录、进度和生成元任务数量；刷新入口显示短暂加载与模拟反馈。
3. 点击“查看”打开当前记录的日志详情；日志编号与所点记录一致，内容明确标识为证据示例，并使用 UTC+8 时间。
4. 点击“筹划设置”调整定时触发、执行周期和超时时间，保存后获得本地模拟反馈。
5. 点击“开始筹划”，经二次确认后显示提交中的加载状态与结果反馈。

## 大区域筹划

1. 从需求管理进入“大区域筹划”，输入完整任务需求编号并载入。
2. 核对目标区域示意、坐标、比例尺、侧摆范围、任务信息与业务内容。
3. 调整侧摆范围；真实步长与联动规则待确认。
4. 点击“开始计算”，经二次确认后显示提交中的加载状态与结果反馈。
5. 非证据编号在脱机原型中显示“未找到对应的本地证据数据”，不伪造任务内容。
6. 对补充证据任务 RW202608260121005，计算完成后自动滚动到结果可视化。
7. 在任务地图和结果地图中执行缩放/复位；在结果区切换目标区域/全球视图、控制载荷图层或播放筹划过程演示。
8. 点击地图观测条带、执行窗口节点或表格记录，三个位置同步突出对应条带；相关控件支持键盘聚焦。
9. 结果分析止于条带明细，不设置计算日志入口。

没有完成态证据的其他任务执行计算时，只提示“计算完成态证据待确认”，不展示补充任务的模拟结果。

用户在删除、取消、完成、开始筹划、开始计算或保存编辑的确认弹层中选择返回时，流程原地结束，不显示成功反馈。

## 阶段 4 · 规划计算管理

### 规划计算

1. 操作员进入“规划计算”，查看当前规划动态、算法、时间、进度和日志。
2. 按创建时间查询规划记录，或刷新脱机样例。
3. 点击“开始规划”核对执行算法、进入规划的任务时间范围和期望执行时间；提交后显示加载与“原型模拟”反馈。
4. 点击“弧段预报”独立启动未来三日预报；按钮锁定，进度弹层依次完成轨道根数加载、两颗卫星计算和结果汇总；该过程不写入规划记录，也不向规划日志输出内容。
5. 计算结束后自动关闭进度弹层，更新最近预报完成时间并打开结果弹层；切换卫星 A / B 查看汇总及按日期分组的弧段卡片。
7. 点击“导出预报结果”展示符合命名规则的模拟文件反馈；真实 Excel 生成未接入。
8. 点击“查看配置”进入规划配置。

### 规划配置

1. 查看当前触发条件、可用路径、执行周期、超时、默认算法和三项时间约束。
2. 点击“编辑配置”进入原页编辑态；取消返回只读态。
3. 点击保存后先确认“全局生效”影响；确认后显示短暂加载和模拟反馈，取消则保留编辑态。

### 算法管理

1. 浏览算法序号、更新时间、名称、状态、备注和操作。
2. 点击“添加算法”，填写名称、编码、启用状态和备注；上传规则因证据不足标记待确认。
3. 点击“删除”先确认具体算法及影响；确认后仅删除本地 Mock，取消不改变记录。
4. “编辑”入口保留，但编辑字段及校验规则待确认，不自行复用新增表单。

### 元任务集合

1. 操作员从需求管理进入“元任务集合”，默认查看任务需求号、元任务号和状态筛选。
2. 展开筛选后可继续填写任务类型、关联计划、优先级和创建时间；点击查询后提交本地筛选，重置清空全部条件。
3. 表格横向滚动查看元任务编号、任务原需求号、类型、执行卫星、创建时间、优先级、状态、元任务标记、筹划编号、开始/结束时间、载荷和侧摆角。
4. 选择记录后点击删除，核对影响数量并二次确认；确认后只更新本地 Mock，取消不改变数据。
5. 导出只提供模拟结果反馈；真实文件结构和下载规则待确认。

## 阶段 4 · 任务计划管理

### 任务计划表

1. 操作员填写计划号、时间、状态、类型、优先级、卫星、地面站或弧段后提交查询，重置同时清除编辑值与已提交值。
2. 表格在页面内横向滚动查看全部 17 个字段，点击查看打开同页详情弹层。
3. 点击关联任务编号时，打开与任务需求列表相同的任务需求详情弹层；没有详情证据的关联任务就近提示「待确认」。
4. 详情主区纵向浏览基本信息及计划类型专用内容；数传详情依次阅读基础参数、时间信息、文件列表和前置遥感计划号；单星/协同成像详情先在左侧阅读成像与目标点参数，同时在右侧查看等高地图，再向下阅读双列时间信息；未知边界标注「待确认」。通过“计划内容/计划模板参数”标签切换结构化参数与原始模板数据。日志默认收起，点击标题栏“日志”按钮后从弹层右侧向外扩展时间轴，主详情区不缩窄，再次点击收起。
5. 点击“手动创建计划”打开共用创建弹层，选择轨控、数传或上注后填写共用字段与类型专用内容；校验通过后确认保存，原型给出本地模拟保存反馈。
5. 发送、删除、取消和完成均先核对数量并二次确认；确认后只更新本地 Mock 或显示模拟反馈。

### 任务计划甘特图

1. 操作员选择日期、时间粒度、阶段和计划类型，切换任务时间轴。
2. 使用今天、前后日、缩放和复位控件查看不同密度；页面保留卫星轨道信息和 UTC+8 当前时间标识。

### 手动测控管理

1. 用户按时间范围、计划号、创建人和卫星筛选手动测控时段。
2. 点击某时段行的“添加计划”，打开与任务计划表相同的手动创建计划弹层，并带入来源时段编号、卫星与有效时间窗。
3. 若已有时段记录存在异常时间，保留原记录；新增计划时由表单校验阻止无效时间写入。
4. 用户可切换轨控、数传或上注类型并完成校验、确认与本地模拟保存；后续表单调整在两个入口同步生效。

1. 操作员筛选测控时段，或打开创建弹层填写开始/结束时间、卫星和备注。
2. 保存前先执行计划冲突检测；真实冲突判定规则待确认，原型仅呈现无冲突模拟结果。

### 发送记录

1. 操作员按计划号、发送时间和成功/失败状态查询发送记录。
2. 点击发送设置，分别选择常规计划和紧急计划的发送方式与时间范围；保存只生成本地模拟反馈。

## 阶段 4 · 数据与上注登记

1. 操作员进入数据接收解析子页面，填写计划、卫星与时间条件并查询，或导出当前筛选结果。
2. 进入星上文件表查看文件存储、大小、传输状态和关联计划；表格宽字段在业务区内滚动。
3. 进入上注文件登记表新增、查看或编辑登记；表单保存只更新本地模拟状态。
4. 点击创建计划时提示目标表单与后端规则待确认，不自行跳转到推测页面。

## 阶段 4 · 系统管理

### 字典管理

1. 操作员在左侧选择字典分类，右侧只显示当前分类字典项。
2. 点击新增或编辑，填写证据已确认的名称、字典值和状态并保存，获得本地模拟反馈。
3. 点击删除后核对具体字典项；确认才删除本地 Mock，取消则不改变数据。

### 系统日志与操作日志

1. 操作员按操作方、模块名称、操作类型和操作时间查询。
2. 在全宽表格内查看各页独立字段与长文本内容，点击重置恢复全部样例。
3. 点击导出只获得模拟反馈；真实文件和权限规则待确认。

## 2026-10-30 需求新增与查看

用户从 0701 侧栏进入“需求新增”，选择载荷和观测方式，填写优先级、侧摆角、采集时间、需求名称与目标区域；通过校验并确认后，原型生成模拟任务号。结果弹窗可继续新增或进入“需求列表”。列表支持按名称/编号、状态、观测方式筛选及查看详情；取消须确认，模拟状态变为“取消中”。关联任务可在“任务需求列表”查看。

需求列表先按状态页签查看数量，再组合筛选观测方式、任务、计划和采集时间；优先级仅在记录中展示。点击卡片“查看”打开四段详情；点击“取消”后阅读影响并勾选知晓后果才能提交，需求进入“取消中”，日志记录模拟状态变化。

目标点与绘制区域的地图浮层均在同一行录入经度、纬度，不提供加减步进按钮。绘制区域可通过地图点击或坐标添加顶点，支持编辑单个顶点、删除、撤销上一步；至少三个顶点时才可完成闭合。双击闭合不额外添加重复顶点。

行政区目标打开后可直接确认中国；选择省后可确认到省，选择市后可确认到市，继续选择区县后可确认到区县。变更上级行政区会清除已选下级。地图边界仍为原型示意，正式边界数据待接入。
目标区域可通过地图点击或坐标输入设置点，或逐点绘制、编辑和闭合多边形；行政区通过省市区县级联选择示意边界。选择 AOI 后，可调整过境计算范围、查看模拟过境清单、点选单条过境并在地图中高亮；图层、缩放、复位和清除独立可用。版本切换位于系统顶栏，不占侧栏菜单空间。

## 2026-11-09 · 需求列表时间与状态查询

1. 用户通过状态页签或“需求状态”下拉框选择状态，两处选中值同步。

## 2026-11-10 · 需求创建与完结

1. 提交需求并创建关联任务后，需求进入“已创建”；列表和详情展示状态，状态页签和下拉框均可筛选。
2. 关联任务规划成功后需求进入“执行中”；跨页自动回写尚待接入，示例数据展示该状态。
3. 用户可对执行中需求点击“完结”，确认需求业务流程已结束后状态改为“已完成”，日志记录本次操作；任务和计划状态不随之修改。
4. 已创建和执行中的需求仍可按既有确认流程取消。
