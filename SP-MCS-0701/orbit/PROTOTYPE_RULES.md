# SP-MCS 双版本原型规则

- `main` 维护 SP-MCS 通用业务；`project/0701` 维护 SP-MCS-0701 项目扩展。通用变更只从 `main` 单向合并到 `project/0701`，不得反向合并整个项目分支。
- `src/version.ts` 是版本、固定地址和跨仓库链接边界；项目业务放在独立视图、数据或明确扩展点。不得靠 CSS 或 DOM 覆盖实现业务规则。
- 导航使用稳定功能 ID；0701 不采用功能要同时裁剪菜单和直接路由，标准源码保留。项目新增占位须明确写“占位”，不算已实现。
- 甘肃卫星、载荷、模型、模板放在项目数据配置；标准多星能力保留。遥控和遥测仅保留目录。
- 标准提交用【标准迭代】或【公共优化】，项目提交用【0701 定制】。先审查未提交改动归属，不得把未知工作提交成标准基线。
- 两版各自构建、lint，检查入口、切换、直接路由、跨仓库导航、资源嵌入，以及 main 合并后项目功能。
