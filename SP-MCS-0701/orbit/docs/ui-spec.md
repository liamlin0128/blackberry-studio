# 前端 UI 设计规范

| 项目 | 内容 |
| --- | --- |
| 产品 | 轨道计算系统（SP-MCS） |
| 技术栈 | `legacy-react-vite`（React / TypeScript / Vite / Tailwind CSS） |
| 版本/日期 | 阶段 3 / 2026-09-24 |
| 依据 | 轨道管理试点、`evidence-inventory.md`、阶段 2 双评审与汇总 |

本规范复用任务规划系统已定稿的 SP-MCS 通用语言；只记录轨道项目实际使用或必需的映射，未重复抄录任务规划的完整规范。

## 1. 保真边界

- 必须保留：轨道管理的卫星筛选、8 列主表、定轨计算配置入口、历史轨道与定轨结果弹层的字段、顺序和入口位置。
- 允许标准化：统一壳层主题、间距、字体、3px 弹层圆角、图标、焦点与悬停。
- 已批准差异：轨道分系统在业务内容上保持独立，但应用壳层严格复用任务规划系统：250px 侧栏、SP 圆章与系统名称、深色顶栏和统一主题令牌；见 `decisions.md` 和阶段 2 V-01/V-03 处置。
- 待确认：检索和手动输入保存后的服务端流程、MD1B 的既有历史明细、加载/错误/无权限。

## 2. 共用令牌

令牌唯一来源为 `src/index.css` 的 `:root`。页面和领域组件引用变量，不在组件内定义第二套 SP-MCS 色彩或尺寸。

| 语义 | 值 | 变量 |
| --- | --- | --- |
| 主操作/链接/焦点 | `#165DFF` | `--sp-color-primary` |
| 主操作悬停 | `#3375D1` | `--sp-color-primary-hover` |
| 当前导航浅底 | `#E8EFFF` | `--sp-color-primary-soft` |
| 一级/二级/弱化文字 | `#1E2B3D` / `#536071` / `#8D9AAC` | `--sp-color-text-*` |
| 白色表面/次级表面/悬停面 | `#FFF` / `#F6F8FB` / `#F4F8FF` | `--sp-color-surface*` |
| 边框/分隔 | `#DFE5ED` / `#E8ECF1` | `--sp-color-border` / `--sp-color-divider` |
| 顶栏渐变 | `#061528 → #0A2139 → #102943` | `--sp-color-header-*` |
| 基础栅格 | `4px`，使用 `4/8/12/16/20/24px` | `--sp-space-1` 至 `--sp-space-6` |
| 标准控件高 | `32px` | `--sp-control-height` |
| 弹层圆角 | `3px` | `--sp-radius-dialog` |
| 壳层 | 顶栏 `64px`、侧栏 `250px`、页签 `40px` | `--sp-shell-*` |

字体为 `Microsoft YaHei, PingFang SC, Arial, sans-serif`。页面标题 `20–22px/600`，分区标题 `16px/600`，正文/表格 `14px`，辅助文本 `12px`；编号和轨道数据块可局部使用等宽字体。

## 3. 布局与组件

| 类型 | 规则 |
| --- | --- |
| 应用壳 | 固定 64px 顶栏、250px 当前系统侧栏、40px 页签；业务工作区为白色画布。 |
| 宽表页面 | 页面使用全宽可用空间；表格容器而非页面承担横向滚动。不得隐藏已证实业务列。 |
| 筛选区 | 字段与主操作分区清晰；不引入未证实筛选字段。 |
| 主次按钮 | 单一区域最多一个 Primary；其他动作使用文字或次级按钮。无真实结果的入口不得伪装为可执行闭环。 |
| 表格 | 与任务规划系统统一：42px 表头与行高、次级表面表头、仅保留水平分隔线、居中列头；不使用外层圆角卡片，当前选择/悬停使用浅主色。 |
| 弹层 | 标题、正文、footer 分区明确，圆角 3px；正文超高时内部滚动；关闭按钮与设置图标使用本地 SVG 且保留 `aria-label`。 |
| 数据块 | 仅结果类弹层使用“区块头 + 值内容 + 复制入口”；配置和历史表不强套该结构。 |
| 分页 | 证据存在的总数、页容量、当前页应保留。没有数据和行为支撑的页码必须禁用，不得无响应。 |

## 4. 状态与数据表达

- 轨道历史在所属弹层内表达，不以页面级“模拟数据”提示干扰评审；证据来源和缺口由文档追溯。
- `更新时间`、`创建时间`使用 `YYYY-MM-DD HH:mm:ss`；`历元时间`在界面显示为 `YYYY-MM-DD HH:mm:ss`，标注为北京时间（UTC+8）。源值来自星时数据时，由服务端/数据源负责换算，前端不自行推导。
- 主页面和历史轨道的时间区块标注为“北京时间（UTC+8）”。
- 高风险“开始计算”在执行前确认；提交后的执行中、成功、失败待确认，不得虚构。
- 加载、错误和无权限不是本阶段的已证实状态，后续获得证据后按统一语义令牌补充。
